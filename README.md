# ЛР3 – Колаборативна фільтрація (варіант 5: вакансії для студентів та випускників)

Запуск (Python 3.10+: numpy, pandas, scipy, scikit-learn, matplotlib):

    cd code
    python lab3.py

- code/lab3.py – рекомендації 1–5 (Пірсон, IUF, ко-рейтинг, кращі сусіди, item-based), підбір параметрів, порівняння; content.py – контентна схожість для оцінки різноманітності
- data/clean – вхідні дані з ЛР1 (матриця взаємодій R_scores.npy, сегменти користувачів, кластери вакансій)
- results/lab2 – рекомендації та пули ЛР2 (для порівняння)
- results/lab3/recommendations_cf.csv – рекомендації 1–5; predictions_100_candidates.csv.gz – прогнози для 100 кандидатів
- figures/lab3 – рисунки
